Installation

Recommandé

macOS & Linux — une seule commande

Détecte la plateforme et l’architecture. Fonctionne sur macOS (Apple Silicon) et Linux.

curl -fsSL https://raw.githubusercontent.com/light-scrap-vidz/light-scrap-vidz/main/install.sh | bash
macOS → Homebrew Ubuntu / Debian → .deb Autres Linux → AppImage

ou installer manuellement

macOS · Homebrew
brew install --cask light-scrap-vidz/tap/light-scrap-vidz
Linux · Debian / Ubuntu
curl -fsSL -o light-scrap-vidz.deb "$(curl -fsSL https://api.github.com/repos/light-scrap-vidz/light-scrap-vidz/releases/latest | grep -o 'https://[^"]*_amd64\.deb' | head -1)" && sudo apt install ./light-scrap-vidz.deb
Téléchargez le .deb depuis la page des releases.
Linux · AppImage
mkdir -p ~/.local/bin && curl -fsSL -o ~/.local/bin/light-scrap-vidz.AppImage "$(curl -fsSL https://api.github.com/repos/light-scrap-vidz/light-scrap-vidz/releases/latest | grep -o 'https://[^"]*_amd64\.AppImage' | head -1)" && chmod +x ~/.local/bin/light-scrap-vidz.AppImage
Ou laissez le script d’installation le poser dans ~/.local/bin.

Désinstallation

Recommandé

macOS & Linux — une seule commande

Retire l’application quelle que soit la façon dont elle a été installée. Vos réglages sont conservés.

curl -fsSL https://raw.githubusercontent.com/light-scrap-vidz/light-scrap-vidz/main/uninstall.sh | bash

ou désinstaller manuellement

macOS · Homebrew
brew uninstall --cask light-scrap-vidz
Linux · Debian / Ubuntu
sudo apt remove light-scrap-vidz
Utilisez sudo apt purge pour retirer aussi les fichiers de configuration.
Linux · AppImage
rm ~/.local/bin/light-scrap-vidz.AppImage

Prérequis

  • macOSApple Silicon (M1 ou plus récent)
  • Linuxx86_64 — Debian 12+ / Ubuntu 22.04+ recommandés ; autres distributions via AppImage
  • Aucune installation manuelle de yt-dlp : il est fourni avec le paquet
